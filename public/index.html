Управление доступностью

Кнопка отключает обработку запросов сервиса (HTTP 503). Процесс остаётся запущенным.

Журнал прохождения запросов

Добавьте товар и оформите заказ. Одинаковый trace связывает точки одного запроса.

Что происходит при заказе

  1. Шлюз передаёт запрос сервису заказов.
  2. Сервис заказов резервирует товары в каталоге.
  3. Сервис заказов сохраняет заказ и передаёт событие сервису уведомлений по HTTP.
  4. Покупатель получает номер заказа.
