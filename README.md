# FORMA — интернет-магазин

Интернет-магазин товаров для дома и рабочего места. Покупатель может искать и фильтровать товары, добавлять их в корзину, менять количество и оформлять заказ с доставкой. Корзина сохраняется в браузере между посещениями.

## Запуск

Нужен Node.js 20 или новее. В PowerShell:

```powershell
cd "Корневая папка проекта"
npm start
```

Откройте http://127.0.0.1:4100. Остановить сервер: Ctrl+C. Внешние пакеты не требуются. Для проверки полного сценария выполните `npm test`.

## Устройство проекта

- `gateway.js` — общедоступный сайт и API (`:4100`).
- `services/catalog.js` — каталог и резервирование остатков (`:4101`).
- `services/orders.js` — оформление и хранение заказов (`:4102`).
- `services/notifications.js` — внутренний журнал уведомлений (`:4103`).
- `data/*.json` — отдельные данные каждого сервиса. Существующие заказы и остатки сохраняются при обновлении приложения.

Сервисы работают в отдельных процессах и общаются по HTTP/JSON. Покупатель через шлюз видит только `GET /api/products` и `POST /api/orders`; общая история заказов и журнал уведомлений наружу не выдаются.

## Оформление заказа

Покупатель вводит имя, телефон, email, город и адрес. Оплата — при получении. Сервис заказов сначала резервирует товары в каталоге, затем сохраняет заказ и записывает внутреннее уведомление. После оформления покупателю показывается номер заказа.

Письма и SMS пока не отправляются: уведомления сохраняются во внутреннем журнале. Стоимость доставки не входит в сумму товаров и требует согласования. Этот проект не подключён к платёжному провайдеру, службе доставки или панели оператора. Для реальной торговли также понадобятся защита персональных данных, надёжная база данных, транзакции резервирования и юридическая информация продавца.

Порты меняются через `GATEWAY_PORT`, `CATALOG_PORT`, `ORDERS_PORT`, `NOTIFICATIONS_PORT`; путь к данным — через `DATA_DIR`.
